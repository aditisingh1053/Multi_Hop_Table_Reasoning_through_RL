\chapter{Reproducing the Experiments}
\label{app:repro}

The results of Chapter~\ref{ch:results} were produced in three steps. Step 1 ran on one NVIDIA T4 GPU; steps 2 and 3 ran on a laptop CPU from the files that step 1 returned. Package versions are pinned in \texttt{requirements.txt}, and \texttt{GPU\_INSTRUCTIONS.md} in the repository describes step 1 on Kaggle, Google Colab and a lab server.

\begin{footnotesize}
\begin{verbatim}
# Step 1 (GPU): data, baselines, all training runs, dev-set evaluation, results_bundle.zip
bash scripts/gpu/run_all_gpu.sh            # resumable; SMOKE=1 runs a 2-3 minute check first
#   clones HybridQA and WikiTables-WithLinks, then runs, in order:
#   scripts/data/extract_wikitables.py      tables and passages read from the git object store
#   scripts/data/build_instances.py --n_train 10000 --n_val 1000
#   tests/test_core.py                 unit tests
#   scripts/data/data_stats.py
#   scripts/train/run_suite.py --seeds-main 5 --seeds-ablation 3

# Step 2 (CPU): second-reader transfer for every selector, in one environment
python scripts/eval/reread_second_reader.py

# Step 3 (CPU): tables, figures, number macros and the PDF
python scripts/analysis/make_assets.py
cd report && tectonic -X compile main.tex
\end{verbatim}
\end{footnotesize}

Single runs can also be started on their own, for example \texttt{python scripts/train/train.py --method bc --seed 0} or \texttt{python scripts/train/train.py --config configs/ppo\_scratch.yaml --seed 0}. The training subset size is set by \texttt{TRAIN\_LIMIT} in \texttt{scripts/common.py} (5{,}000).

\chapter{Repository Layout}
\label{app:layout}

\begin{footnotesize}
\begin{verbatim}
configs/        one YAML file per experiment (reward, environment, optimiser)
data/           raw clones, processed graphs and embeddings, reader caches (not versioned)
docs/           planning documents from the first phase of the project
papers/         PDFs collected in the first phase
report/         this report: main.tex, chapters/, generated/, figures/, references.bib
reports/        literature synthesis behind Chapters 3 and 4
research_notes/ per-topic notes of the literature search, with verified BibTeX
results/        baselines/, runs/<name>_s<seed>/, logs/, pilot/, summary files
scripts/        command-line entry points (see Appendix A)
src/mhtrl/      data, environment, policy, reader, rollout, rl/ (PPO, GRPO, REINFORCE, BC)
tests/          unit tests
\end{verbatim}
\end{footnotesize}
